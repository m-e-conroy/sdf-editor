# Scene Layout

# Introduction
 geometry of scene is constructed from one or more objects. These objects can range from lights to illuminate your scene, basic 2D and 3D shapes to fill it with models, armatures to animate those models, to cameras to take pictures or make video of it all.
Each Blender object type (mesh, light, curve, camera, etc.) is composed from two parts: *Object*and *Object Data*(sometimes abbreviated to “ObData”):
**Object**Holds information about position, rotation and size of particular element.**Object Data**Holds everything else. For example:**Meshes :**Store geometry, material list, vertex groups, etc.**Cameras :**Store focal length, depth of field, sensor size, etc.
Each object has link to its associated object-data , and single object-data may be shared by many objects.

# Object Types
Reference**Mode :**Object Mode**Menu :**Add**Shortcut :**Shift - 
New objects can be created with*Add*menu in 3D Viewport’s header.
**Mesh**Objects composed of vertices, edges and polygonal faces and can be edited extensively with Blender’s mesh editing tools. See Mesh Primitives .**Curve**Mathematically defined objects which can be manipulated with control handles or control points (instead of vertices), to edit their length and curvature. See Curves Primitives .**Surface**Mathematically defined patches that are manipulated with control points. These are useful for simple rounded forms and organic landscapes. See Surfaces Primitives .**Metaball**Objects formed by mathematical function (with no vertices or control points) defining 3D volume in which object exists. Meta objects have liquid-like quality where when two or more metaballs are brought together, they merge by smoothly rounding out connection, appearing as one unified object. See Meta Primitives .**Text**Create two-dimensional representation of text.**Volume**Container for OpenVDB files that is generated by other software or Blender’s Fluid Simulator .**Grease Pencil**Objects created by drawing strokes. See Grease Pencil Primitives**Armature**Used for rigging 3D models to make them pose-able and animatable.**Lattice**Non-renderable wireframes commonly used for deformation of other objects with help of Lattice Modifier .**Empty**Null objects that are simple visual transform nodes that do not render. They are useful for controlling position or movement of other objects.**Image**Empty objects that display images in 3D Viewport. These images can be used to aid artists in modeling or animating.**Image Plane**Adds mesh plane with materials and texture from image file. dimensions of plane are calculated to match aspect of image file.**Light**Empty objects that emit light and are used for lighting scene in renders.**Light Probe**Used by EEVEE render engine to record lighting information for indirect lighting.**Camera**This is virtual camera that is used to determine what appears in render.**Speaker**Empty objects that bring source of sound to scene.**Force Field**Empty objects that give simulations external forces, creating movement, and are represented in 3D Viewport as small control objects.**Collection Instance**Lets you select from list of existing collections. Once selected, empty object will be created, with instance of selected collection (collection instancing active).
## Common Options
You can change options of object in Adjust Last Operation panel after creating it:**Type**You can change type of some objects after their creation with selector.**Radius/Size**Sets starting size.**Align**Rotates new object so that it is aligned in one of following manners:**World :**Aligns object to global space axes, i.e. object’s front faces negative Y axis (default).**View :**Aligns object to view space axes, i.e. object’s front faces viewport’s point of view.**3D Cursor :**Aligns object to match rotation of 3D Cursor .**Location**Objects are placed, by default, at position of 3D Cursor. These values let you place object in other position.**Rotation**Values let you rotate object so that default rotation is overridden.

# Object Origin
Each object has origin point. location of this point determines where object is located in 3D space. When object is selected, small dot appears, denoting origin point. location of origin point is important when translating, rotating or scaling object. See Pivot Points for more.
 color of origin changes based on selection state of object.**Yellow :**Object is active.**Orange :**Object is selected, but not active.**White :**Object is not linked and not selected.**Turquoise :**Object is linked.**Light Turquoise :**Object is selected, linked, but not active.
Note
Colors are themeable and might appear different. colors described here are from default Dark Theme.
## Set Origin
Reference**Mode :**Object Mode**Menu :**Object ‣ Set Origin
 object origin and geometry can be moved relative to each other and to 3D cursor.**Type**
**Geometry to Origin**Moves model to origin and this way origin of object will also be at center of object.**Origin to Geometry**Moves origin to center of object.**Origin to 3D Cursor**Moves origin of model to position of 3D cursor.**Origin to Center of Mass**Moves origin to calculated center of mass of model (assuming mesh has uniform density).**Center**Median Point Center, Bounding Box Center
Tip
To transform object’s origin directly, enable Affect Only Origins in*Tool Settings Options*.
