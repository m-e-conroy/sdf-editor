# App Builder Tech Stacks

## 🌐 Web Frontend (Default)
| Layer | Recommended |
| :--- | :--- |
| **Framework** | Next.js 14+ (App Router) |
| **Styling** | **Vanilla CSS** (Variables, Nesting, Modules) |
| **Typography** | Google Fonts (Inter, Outfit, Roboto) |
| **State** | Zustand / Context API |
| **Icons** | Lucide React / Tabler Icons |

## 🛠 Full-Stack & Backend
| Layer | Tech | Alt |
| :--- | :--- | :--- |
| **Framework** | Next.js | NestJS |
| **Database** | PostgreSQL + Prisma | Supabase |
| **Auth** | NextAuth.js / Clerk | Firebase Auth |
| **Storage** | Cloudinary / Uploadthing | S3 |

## 📱 Mobile & Other
| Platform | Technology |
| :--- | :--- |
| **Mobile** | Expo (React Native) |
| **Desktop** | Electron / Tauri |
| **CLI** | Node.js + Commander |

## 💎 Design Standards
1. **Aesthetics**: Vibrant colors, dark modes, glassmorphism.
2. **Typography**: Modern fonts (no defaults).
3. **Animations**: Smooth transitions, GSAP/CSS micro-animations.
4. **Assets**: No placeholders. `generate_image` or actual.
5. **SEO**: Meta tags, semantic HTML, one `<h1>`.
